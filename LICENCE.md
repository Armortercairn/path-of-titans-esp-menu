## 🧩 About

**Path of Titans Companion** is a curated list of Path of Titans open-source tools:

- **Overlays** — on-screen helpers, layout notes, marker viewer, spawnpoint switcher
- **Quality-of-Life Helpers** — skin catalog, dino manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Marker Switcher — study from any spawn point
- Show Markers — visualize resource and nest markers
- Route Notes — record and review travel runs
- Playback Speed — adjust movement playback for study (0.1x to 5x)

### Wallhack
- Skin Catalog — browse skins, colors, patterns, and growth stages
- Custom Dino Notes — organize player cosmetics
- Track Highlight — improved trail visibility

### Aimbot
- Practice Mode Notes — segment study on any map layout
- Growth Stage Notes — manually review growth stages mid-run
- Stamina Buffer Notes — chain complex maneuvers in the editor
